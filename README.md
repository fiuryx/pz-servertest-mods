# pz-servertest-mods

Mods propios, fixes y pack de traducción al español de España del servidor de Project Zomboid **servertest** (Build 42).

Cada carpeta de `mods/` es una carpeta de subida al Workshop tal cual (`workshop.txt`, `preview.png`, `Contents/mods/<ID>/...`): se copia a `%UserProfile%\Zomboid\Workshop\` y se sube desde el juego.

## Normas del proyecto

- Textos en español de España.
- Nunca un `%` suelto en los textos del juego (usar `%%` o reformular; `%1`, `%s`, `%d` se mantienen).
- Cada fix es un mod independiente, con descripción del Workshop en inglés e imagen propia.
- Las traducciones de nuestros mods y fixes también se guardan en el pack de traducciones.
- Quitar un mod del servidor no implica quitar sus textos del pack.
