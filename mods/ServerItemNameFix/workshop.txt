description=[h1]Server Item Name Fix (B42)[/h1]
description=A dedicated server loads its translations before the mods are active, so every text it builds from a mod key stays as a code. Cooked dishes show [b]"Bowl of Base.RicePot"[/b] instead of [b]"Bowl of Rice"[/b], and the note that rises over your head when a modded skill levels up shows [b]"IGUI_perks_Dancing"[/b].
description=
description=[b]Server part[/b]
description=[list]
description=[*]Reloads the translations once the server has started, so they include every active mod.
description=[*]Refreshes the skill names, so level-up and XP notes from modded skills (Lifestyle, etc.) show the real name.
description=[*]New item names built by the server use the translated names.
description=[*]Sandbox setting [b]Server language[/b] (a code such as ES, EN, FR, DE) to choose the language of those texts. Empty keeps the server's own language.
description=[/list]
description=
description=[b]Client part[/b]
description=[list]
description=[*]Replaces item codes left in names (items made before, or by a server without this mod) with the item name in your language.
description=[*]Works on your inventory, your bags and the containers you have open. Display only: nothing is changed for other players.
description=[/list]
description=
description=Multiplayer safe, can be added or removed at any time.
