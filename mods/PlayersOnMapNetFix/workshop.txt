title=Players On Map - Network Fix (B42)
description=[h1]Players On Map - Network Fix (B42)[/h1]
description=Add-on for [b]Players On Map[/b] (required). Same dots and names on the map, a lot less network traffic.
description=
description=[h2]The problem[/h2]
description=[list]
description=[*]Every client sends its position to the server about [b]10 times per second[/b], all the time, even with the map closed.
description=[*]The server sends the full player list to [b]every client 10 times per second[/b].
description=[*]On a server with 10 players that is around 100 messages per second in each direction just for the map, on top of the game's own traffic. Measured on our server: almost 13,000 messages in 24 minutes from a single player.
description=[/list]
description=
description=[h2]What this changes[/h2]
description=[list]
description=[*]The server sends the player list [b]once per second[/b], and nothing while nobody is online.
description=[*]Clients send their own position at most [b]once every 5 seconds[/b]. The server already knows where everyone is and uses its own data when that message is older than half a second, so nothing is lost.
description=[*]Nearby players (within 100 tiles) are still drawn from your own game, so their dots keep moving smoothly. Far players update once per second.
description=[*]Sandbox options, names, factions and admin rules work exactly as before.
description=[/list]
description=
description=Works in multiplayer, does nothing in singleplayer, and can be added or removed at any time. Load it after Players On Map. All credit for Players On Map goes to its author.
description=
description=[h2]Changelog[/h2]
description=[list]
description=[*]Fixed an error spam with other mods that call sendServerCommand/sendClientCommand (for example Fast Forward): arguments are now passed through exactly as received.
description=[/list]
