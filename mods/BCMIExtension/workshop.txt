description=[b]How it works[/b]
description=[list]
description=[*]Reuses the icons of Better Context Menu Icons and the game item textures, plus 13 new icons drawn in the same style.
description=[*]Only fills options that still have no icon: it never replaces an existing icon or item texture.
description=[*]Works with any language (matches the translated option text). Mods that are not installed are simply skipped.
description=[*]Client-side only, multiplayer safe, can be added or removed at any time.
description=[/list]
