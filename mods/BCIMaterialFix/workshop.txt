description=[h1]Better Clothing Info - Material Translation Fix (B42)[/h1]
description=[b]Better Clothing Info[/b] shows the clothing material using the raw value from the item script (for example "cotton"), so it is never translated. This small patch shows a proper, translated name instead.
description=
description=[h2]Details[/h2]
description=[list]
description=[*]Only changes the "Material" row of the Better Clothing Info tooltip.
description=[*]Known materials: cotton, denim, leather, wool, polyester, nylon, silk, kevlar, rubber and fur. Unknown values are shown as before, just capitalised.
description=[*]English and Spanish texts. Other languages can be added with UI_BCIMF_Fabric_<material> keys.
description=[*]Client side only. Safe to add or remove at any time, also on servers.
description=[/list]
description=[b]Requires[/b] Better Clothing Info (EURY_CLOTHINGINFO).
