title=Fast Forward - Network Desync Fix (B42)
description=[h1]Fast Forward - Network Desync Fix (B42)[/h1]
description=Patch for [b]Fast Forward[/b] that fixes the multiplayer desync where players in the same vehicle (or watching each other drive) see the car in different places.
description=
description=[h2]The problem[/h2]
description=To make timed actions finish faster on the server, Fast Forward moves the server network clock with [i]GameTime.setServerTimeShift()[/i]. Clients sync their clock to the raw server clock, so after any fast forward or pause every vehicle and player update from the server looks like it comes from the future. The shift is never undone, so the desync stays until the server restarts.
description=
description=[h2]What this patch does[/h2]
description=[list]
description=[*]Keeps the server clock shift at 0 at all times, so network timing stays correct.
description=[*]Instead, changes the end time of each running timed action, so reading, crafting, etc. still finish faster while time is accelerated and freeze while paused, like before.
description=[*]Everything else from Fast Forward (panel, speed voting, cooking) keeps working as usual.
description=[/list]
description=
description=[h2]Details[/h2]
description=[list]
description=[*]Server side only, no texts. Load it after Fast Forward.
description=[*]Restart the server after adding it, so any clock shift left by Fast Forward is cleared.
description=[*]Does not include or change any file from Fast Forward.
description=[/list]
description=[b]Requires[/b] Fast Forward.
