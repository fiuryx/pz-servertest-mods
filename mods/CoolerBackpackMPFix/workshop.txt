description=[h2]The problem[/h2]
description=Cooler Backpack gives zombies a chance to drop its upgrades (TCM upgrade, battery capacity upgrade and oven bag upgrade) when they die. That code is in a server file, but in Build 42 multiplayer server files also run on the clients. So the player who kills the zombie rolls the chance a second time on their own game. When that roll hits, the upgrade shows up on the corpse only for that player: the server does not know it exists, and it [b]cannot be moved to the inventory[/b] no matter what you try.
description=
description=[h2]What this changes[/h2]
description=[list]
description=[*]The client-side copy of those drops is skipped, so you only see the real drops rolled by the server, which everyone can loot normally.
description=[*]Drop chances stay exactly as set in the sandbox options.
description=[*]Singleplayer and the server are not touched.
description=[/list]
description=
description=Upgrades that are already stuck on a corpse disappear after reconnecting. Can be added or removed at any time. Load it after Cooler Backpack. All credit for Cooler Backpack goes to its author.
