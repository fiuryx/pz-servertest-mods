description=[h1]Defecation Fixes (B42)[/h1]
description=Small client-side fixes for the [b]Defecation[/b] mod in Build 42.22.
description=
description=[h2]1. Toilet option translation[/h2]
description=Defecation adds the "Defecate" option to the toilet menu with fixed English text. This patch renames it with the mod's own translation key (ContextMenu_Defecate), so it shows in your game language (for example "Defecar" in Spanish).
description=
description=[h2]2. Clean soiled clothes at water sources[/h2]
description=Defecation adds "Clean the feces" inside the water source submenu, looking the submenu up by its name. Since 42.22 builds that menu in Java, the lookup can fail and the option never appears. This patch checks the menu after Defecation has filled it and, if the option is missing, adds it: inside the water source submenu when found, otherwise at the top of the menu.
description=[list]
description=[*]Same rules as Defecation: 300 ml of bleach or cleaning liquid and 7 L of water within 10 tiles.
description=[*]Uses Defecation's own wash action and texts, so the result is identical.
description=[*]If Defecation's own option works, it does nothing, so it never shows twice.
description=[/list]

description=[h2]3. Take the trousers off and put them back on[/h2]
description=When defecating on purpose (toilet or ground), Defecation only plays a squat animation and the clothes stay on. This patch takes off the clothing that covers the groin (trousers, shorts, skirts, long johns, underwear) with the game's own unequip action before squatting, and puts it back on afterwards. If you are interrupted, the clothes are put back on too. Not in vehicles; accidents are not touched.
