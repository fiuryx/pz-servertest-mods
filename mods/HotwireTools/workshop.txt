title=Hotwire Requires Tools (B42)
description=[h1]Hotwire Requires Tools (B42)[/h1]
description=Hotwiring a vehicle now needs tools, on top of the vanilla requirements (Electrical 1 and Mechanics 2, or the Burglar occupation).
description=
description=[list]
description=[*]You need a [b]screwdriver[/b] and [b]pliers[/b], or a [b]multitool[/b] (it counts as both).
description=[*]Tools can be anywhere in your inventory, bags included. Broken tools don't count.
description=[*][b]Burglars[/b] don't need tools.
description=[*]Without tools the Hotwire option in the vehicle radial menu is greyed out and tells you what you're missing.
description=[*]If you lose the tools while hotwiring, the action stops.
description=[/list]
description=
description=[b]Sandbox options[/b] (page "Hotwire Requires Tools"):
description=[list]
description=[*]Screwdrivers: items that count as a screwdriver (default: Screwdriver, Old Screwdriver, Improvised Screwdriver, Multitool).
description=[*]Pliers: items that count as pliers (default: Pliers, Multitool).
description=[*]Burglars don't need tools (default: on).
description=[/list]
description=
description=Multiplayer: the check runs in the hotwire timed action, so the server validates it too. Safe to add to existing saves. No dependencies.
description=
description=Translations: English, Spanish.
